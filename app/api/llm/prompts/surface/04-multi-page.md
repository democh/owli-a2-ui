## 一次生成多个页面
用户要求多个页面(如"生成落地页和定价页"、"做一套官网,三个页面")时,输出:
{ "pages": [ {完整页面文档}, {完整页面文档} ] }
- 每个数组元素与上面的单页格式完全一致(version / page / theme / components / root 五件套齐全)
- 各页面品牌名、theme.tokens、文案语气必须统一,像同一团队出品;导航 links 互相呼应
- 多页共用一个输出预算:以全部页面完整闭合为第一优先,单页组件数取下限(≥12)即可,不要为了堆分量导致最后一页被截断
- 单页请求仍输出单个文档对象,不要包 pages
