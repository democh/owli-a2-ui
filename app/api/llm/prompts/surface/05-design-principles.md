## 设计规范(决定页面"好不好看",务必遵守)

### 0. 先定美学方向,再动手
- 用 theme.tokens 与组件组合坚决执行所选方向,不要生成"放之四海皆准"的平庸页面
- 品牌页(营销/官网/作品集):追求记忆点与视觉冲击,布局大胆、留白奢侈、标题有态度
- 产品页(看板/后台/表单):追求效率与一致性,信息密度高、控件规整、色彩克制
- 反面清单(AI 味,禁止):通篇紫色渐变 + 圆角卡片网格;所有区块都是"图标+标题+一句话"的三件套;首屏就是平庸的居中大标题 + 两个按钮;无叙事目的的轮播;空洞的形容词堆砌("极致""领先""一流");每个页面都是同样的 3 列特性网格

### 1. 排版(最直观的品质信号)
- 层级跳跃要果断:Hero 标题与正文至少 3 倍字号差,不要 1.5 倍的温吞对比;Title level=1 全页只出现一次
- 字重对比用极端:标题 700-800,正文 400,不要 500 vs 600 的模糊地带
- 行长控制:正文段落用 Container 限宽(约 600-700px,中文单行 30-38 字),禁止整行贯穿屏幕的长段落
- 数字与关键指标用大号粗体(Statistic / StatsRow),让它们成为视觉锚点
- 每屏只突出一个主行动:主按钮(primary)一处,其余行动一律 outline/ghost 退后,不要满屏争抢视线的按钮

### 2. 色彩(纪律大于创意)
- 比例:中性色(背景/文字/边框)占 70-80%,辅助色 15-20%,主色仅 5-10% 用于 CTA 与强调
- primary 一个主色贯穿按钮、链接、激活态;accent 只做小面积点缀(图标、徽章、图表首色)
- 同页色相不超过 2 个;语义色固定:成功绿 / 警告橙 / 错误红,不挪作装饰
- 对比度:正文与背景 ≥ 4.5:1;主按钮白字配深主色,浅主色背景必须配深色文字

### 3. 主题令牌(theme.tokens,8 个字段全部给出)
- primary 品牌主色(按钮/激活态);accent 点缀色(图标/徽章/图表);background 页面底色;surface 卡片/次级底色;text 正文色;mutedText 次要文字;radius 圆角 4-16(企业风 4-6,消费品牌 10-16);font 留空即可
- theme.preset 保持与用户所选风格预设一致(shadcn 中性黑 / antd #1677ff / element #409eff / custom 自由发挥);tokens 在该预设基准上按品牌气质微调
- 颜色必须是合法 hex(或 rgba),深浅搭配保证对比度;深色科技风可把 background/text 反转(深底浅字),此时 surface 用比 background 略亮的深色

### 4. 间距与布局
- 全文统一 8pt 网格:间距只取 8/12/16/24/32/48/64/96 阶梯;Section padding 48-96,卡片 padding 20-28
- 留白是设计的一部分:相邻区块之间要有呼吸感,不要密不透风;每屏只有一个视觉锚点,次要信息用 Text variant=muted 退后
- 布局多样化:Grid 卡片、左右分栏(Row ratios)、StatsRow 大数字、LogoCloud、Image 穿插使用,避免所有区块同一种排列;相邻区块可深浅底色交替,形成阅读节奏
- 移动端可点击区域高度 ≥ 44px,元素间距 ≥ 16px

### 5. 细节质感
- 卡片阴影要轻(1-2 层模糊),边框 1px 浅灰,拒绝厚重投影
- 圆角全局统一:radius 令牌定一个值,所有组件遵守,不要圆角混搭
- Hero 标题 ≤ 16 字且有记忆点(用 \n 控制分行);副标题一句话讲清价值主张
- 营销页至少 1-2 处使用 Image(alt 写具象的画面描述,如 "产品经理在双屏前审阅实时数据看板"),不要让页面全是文字与色块
- 数据可视化优先:凡是能量化的内容(增长、规模、对比)优先用 StatsRow / Chart / Progress 表达,而不是干巴巴的文字
