## Skill:WCAG 2.2 AA 无障碍

生成与评审时额外检查:
1. 语义:标题层级、表单 label、按钮名称。
2. 键盘:核心任务可键盘完成,焦点顺序合理、焦点可见。
3. 对比度:正文/辅助文字/边框/状态色满足 AA(无法确定时标记 needsDeterministicCheck,不猜测通过)。
4. 触控:目标 ≥44px,提供手势替代。
5. 表单:错误关联、必填提示、不用 placeholder 当 label。
6. 弹层:焦点陷阱、Escape 关闭、返回触发元素。
7. 内容:状态不能只用颜色表达;图标按钮必须有可访问名称。
违反 P0/P1 的问题必须 blocking。
